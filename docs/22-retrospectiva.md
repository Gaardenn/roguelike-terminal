# Retrospectiva — Roguelike de Terminal

Reflexão pessoal sobre o processo completo, do planejamento ao release.

## O que funcionou bem no processo?
Seguir o roadmap, manter um padrão sequencial de grandes marcos planejando bem o projeto antes de programar

## O que você aprendeu que não sabia antes?
Melhorei os processo, aprendi sobre terminais e bastante sobre release e organização de projeto no GitHub

## O que você faria diferente se começasse de novo?
Talvez no balanceamento e no processo criativo detalhar mais

## Qual parte foi mais difícil?
Testar nos terminais diferentes e balancear a dificuldade

## Qual parte você mais gostou de fazer?
Programar, organizar o repositório e a parte criativa

## O processo de "empresa de software" (planejamento → design → dev →
## testes → release) valeu a pena pra esse projeto?
