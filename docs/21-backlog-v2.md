# Backlog — Ideias para v2

Consolidado de tudo que ficou de fora do MVP intencionalmente, mais
ideias que surgiram durante o desenvolvimento.

## Do escopo original (01-escopo.md)
- [ ] Múltiplos tipos adicionais de monstros e itens
- [ ] Sistema de inventário mais completo (slots dedicados de equipamento)
- [ ] Sistema de níveis/experiência (XP)
- [ ] Save/load de progresso (fora do permadeath puro)
- [ ] Mensagens de log com histórico navegável (scroll para trás)
- [ ] Itens/armadilhas especiais no mapa

## Ideias de sistemas (mencionadas durante o design, mas fora do MVP)
- [ ] Fog of war (áreas não exploradas ficam escondidas)
- [ ] Ação formal de "fugir" do combate (hoje é só se afastar)
- [ ] Chance de acerto crítico/erro (miss) no combate
- [ ] Comportamento de IA `idle` (monstro parado até perceber o jogador) - 
      documentado mas nunca usado por monstro nenhum
- [ ] Habilidades especiais para o chefe final (hoje ele só persegue e ataca)
- [ ] Mais variedade na geração do mapa (loops/conexões extras entre salas,
      não só uma "espinha dorsal" sequencial)

## Ideias de UI/UX
- [ ] Tela de ajuda dedicada (além do resumo do menu)
- [ ] Customização visual do personagem (sugestão do testador externo)
- [ ] Indicador visual de alcance da Machadinha antes de arremessar
- [ ] Animações simples (ex: flash ao tomar dano)

## Ideias técnicas
- [ ] Empilhamento de itens iguais no inventário
- [ ] Suporte mais robusto a terminais com cor parcial (ex: PowerShell -
      hoje é uma limitação conhecida, não resolvida)
- [ ] Mais telas de tamanho adaptável (hoje é fixo em 81x25 mínimo)

## Ideias de conteúdo
- [ ] Mais variações de monstros com lore própria (seguindo o estilo dos
      3 já criados: Deus da Morte, Perturbado de Energia, Mulher Afogada)
- [ ] Itens com descrições mais ricas (hoje são bem funcionais/diretas)
- [ ] Mias de um chefe, ou chefes intermediários em andares anteriores
