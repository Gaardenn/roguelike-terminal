# Roguelike de Terminal

Um roguelike em ASCII, com geração procedural de masmorras e combate por
turnos, rodando em terminal (Windows/Linux/Mac).

## Como rodar
1. Crie e ative um ambiente virtual: `python3 -m venv venv`
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python3 src/main.py`

## Documentação
Veja a pasta `docs/` para escopo, GDD e arquitetura do projeto.
